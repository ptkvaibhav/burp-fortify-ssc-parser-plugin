# Artwork sources

Original artwork for this project (MIT licensed, like the rest of the repository).
`icon.svg` / `logo.svg` produce the plugin images in `src/main/resources/images/`
(icon 50×50, logo 225×50, transparent PNG), and `diagram.html` produces the
`how-it-works-*.png` README diagram (body class `light` or `dark`, rendered at 2× scale).

Render with any headless browser, e.g. Playwright `page.screenshot({ omitBackground: true })`.
